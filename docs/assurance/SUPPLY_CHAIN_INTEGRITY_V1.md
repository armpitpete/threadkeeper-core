# Core Supply-Chain Integrity v1

The software interpreting project authority must itself be attributable.

A releasable Core build should expose source commit, version, Go/runtime identity, binary SHA-256, dependency/SBOM identity and build-provenance identity. Release automation must preserve these values with the artifact and conformance evidence.

Supply-chain provenance proves which software performed an operation; it does not make that software an authorised decision actor.
